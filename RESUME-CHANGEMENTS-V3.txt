AVANT : App → RGPD → Collèges → Voter → Succès

APRÈS : App → RGPD → IDENTITÉ (Nom/Prénom) → Collèges → Voter → Succès
                        ↓
                   Si déjà voté → "Réponse enregistrée" + Modifier option


PREMIER VISITEUR (Sophie) :
1. Ouvre app
2. Accepte RGPD
3. Voir écran "Qui êtes-vous ?"
   └─ Rentre prénom + nom
   └─ Clic "Continuer"
4. Aller sondage + vote
5. Succès affiche : "Sophie Martin - Réponse validée ✅"


VISITEUR DÉJÀ VOTÉ (Marc) :
1. Ouvre app
2. Accepte RGPD
3. Voir écran "Qui êtes-vous ?"
   └─ Rentre prénom + nom
   └─ Clic "Continuer"
4. Système détecte : Marc Martin a déjà voté
5. Affiche écran SPÉCIAL :
   ┌─────────────────────────────┐
   │ ✅ Réponse déjà enregistrée │
   │ Marc Martin                 │
   │ Priorités actuelles : [...]  │
   │ [✏️ Modifier] [← Retour]    │
   └─────────────────────────────┘
6. Marc peut :
   a) Modifier → Refaire sondage (1x seulement)
   b) Retour → Écran identité


MODIFIER RÉPONSE (Laurent) :
1. Voir "Réponse déjà enregistrée"
2. Clic "✏️ Modifier ma réponse"
3. Ancien vote supprimé ✗
4. Refaire sondage
5. Succès affiche :
   ✏️ Modification : Vous avez modifié votre réponse
6. Tenter 2e modification → BLOQUÉ ❌
   Message : "Vous avez déjà modifié votre réponse une fois."

Avant : Vérification par IP seule
  Risque : Plusieurs personnes même IP (même famille)
           → Bloquer après 1er vote

Après : Vérification par (IP + Prénom + Nom)
  ✅ Chaque personne identifiée
  ✅ Plusieurs votes même IP = OK si noms différents
  ✅ Même personne même IP = OK pour modification 1x
  ✅ Vérification plus précise
  ✅ Traçabilité complète

Exemple :
IP 192.168.1.100 → 3 personnes :
  ✅ Vote 1 : Marie Dupont (premier vote)
  ✅ Vote 2 : Pierre Dupont (frère, autre vote)
  ✅ Vote 3 : Jean Martin (ami, autre vote)
Tous différents = Tous acceptés ✅

Modification :
  ✅ Marie peut modifier 1x
  ✅ Après 2e tentative = BLOQUÉ
