✅ ÉTAPE 2 : Déployer le Script (1 min)

1. Dans Apps Script : Menu > "Nouveau déploiement"
2. Type : "Application Web"
3. "Qui a accès" : "N'importe qui"
4. Cliquer "Déployer"
5. COPIER l'URL du déploiement :
   https://script.google.com/macros/d/[COPIEZ_CEL_CI]/userwithscript

✅ ÉTAPE 3 : Configurer index.html (1 min)

1. Ouvrir index.html
2. Chercher ligne ~800 : GOOGLE_APPS_SCRIPT_URL = ""
3. Remplacer par l'URL de déploiement :
   const GOOGLE_APPS_SCRIPT_URL = "https://script.google.com/macros/d/...";
4. Enregistrer
