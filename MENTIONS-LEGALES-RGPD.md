## VERSION COURTE (dans la modale - déjà intégrée)

```
À propos de ce sondage
Ce sondage est destiné aux élections professionnelles 2026 SPP-PATS.
Il permet de collecter vos priorités de revendications de manière sécurisée et confidentielle.

Protection de vos données (RGPD)
Conformément à la Loi Informatique et Libertés et au RGPD :

Données collectées : Votre collège, vos priorités de revendications, et votre adresse IP (pour éviter les doublons)
Finalité : Collecter les priorités des agents pour les négociations syndicales
Conservation : Les données sont conservées pendant la durée du processus électoral (env. 3 mois)
Destinataires : SPP-PATS Syndicat Autonome et représentants autorisés
Sécurité : Vos données sont protégées par HTTPS et hébergées de manière sécurisée
Vos droits : Accès, rectification, suppression - contactez le syndicat

Confidentialité
Vos réponses sont confidentielles. Seule votre IP est enregistrée pour éviter les doublons.
Votre identité n'est jamais associée à vos votes.

Interdictions
Une seule réponse par adresse IP
Les VPN et proxies sont détectés et bloqués
Toute tentative de fraude sera enregistrée
```

### Article 1 : Organisateur du sondage

### Article 2 : Nature du sondage

**Objet :**
Ce sondage permet de collecter les priorités de revendications des agents en vue du processus d'élections professionnelles SPP-PATS 2026 (vote électronique du 02 au 09 juin 2026).

**Caractéristiques :**
```
- Type : Sondage de priorités
- Population cible : Agents des services de pompiers (pompiers-militaires)
- Collèges : Officiers, Non-Officiers (SPP), PATS
- Durée du sondage : [Dates précises à ajouter]
- Modalité : Sondage en ligne anonyme
```

### Article 3 : Données traitées (Finalités)

**Données collectées :**
1. **Données de catégorisation**
   - Collège professionnel (Officiers / Non-Officiers / PATS)
   
2. **Données de vote**
   - Les 6 priorités de revendications sélectionnées par collège
   
3. **Données de sécurité**
   - Adresse IP (pour éviter les doublons)
   
4. **Données temporelles**
   - Date et heure du vote

**Données NON collectées :**
```
✗ Identité (nom, prénom, numéro agent)
✗ Grade ou fonction
✗ Affectation
✗ Toute donnée personnelle identificatrice
✗ Géolocalisation précise
✗ Informations financières
```

**Finalités du traitement :**
```
1. Déterminer les priorités de revendications des agents
2. Informer les négociations syndicales avec l'employeur
3. Lutter contre la fraude électorale (anti-doublon)
4. Améliorer le processus démocratique interne
5. Produire des statistiques anonymes
```

### Article 4 : Fondement légal (Article 6 RGPD)

Le traitement est justifié par :

**1. Consentement (Article 6.1.a RGPD)**
```
✓ Modale d'acceptation RGPD au lancement
✓ Case à cocher obligatoire
✓ Acceptation explicite et libre
✓ Possibilité de refuser
```

**2. Obligation légale (Article 6.1.c RGPD)**
```
✓ Loi de modernisation sociale (dialogue social)
✓ Directive européenne élections professionnelles
✓ Accord collectif SPP-PATS
✓ Droit du travail français
```

**3. Intérêt légitime (Article 6.1.f RGPD)**
```
✓ Démocratie syndicale et consultation des agents
✓ Légitimité du syndicat à représenter ses membres
✓ Nécessité de connaître les priorités du terrain
✓ Intérêt des agents supérieur au risque minimal d'IP
```

### Article 5 : Destinataires

**Qui a accès aux données :**

**1. Bureau syndical SPP-PATS**
```
- Membres du bureau directeur
- Représentants élus aux négociations
- Responsables des dossiers revendications
```

**2. Délégué à la Protection des Données**
```
- Veille à la conformité RGPD
- Gère les demandes d'accès
- Supervise la suppression
```

**3. Fournisseurs techniques**
```
- Vercel (hébergement app en ligne)
- Google Sheets (si activé pour centralisé)
- ipapi.co (API détection IP/VPN)
```

**4. Autorités légales (si demande)**
```
- CNIL (Commission Nationale Informatique et Libertés)
- Autorités de police (si soupçon fraude)
- Tribunal (sur mandat)
```

**Les données ne sont JAMAIS :**
```
✗ Vendues à des tiers
✗ Données à des sous-traitants non autorisés
✗ Partagées publiquement
✗ Utilisées pour profilage
✗ Communiquées à l'employeur
```

```
Durée : 3 mois
```


### Article 7 : Sécurité des données

**Mesures techniques :**
```
1. Chiffrement en transit (HTTPS/TLS 1.3)
   - Tous les échanges are chiffrés
   - Certificat SSL auto-signé par Vercel
   - Pas d'interception possible

2. Chiffrement au repos (Google Sheets)
   - Google chiffre automatiquement
   - Clés gérées par Google
   - Conformité SOC 2 Type II

3. Pseudonymisation
   - IP stockée mais pas liée à identité
   - Aucun prénom, nom, matric
   - Impossible de relier au votant

4. Isolation du réseau
   - App sur Vercel (infrastructure Google Cloud)
   - Pas de base de données exposée
   - Firewalls et protections automatiques
```

**Mesures organisationnelles :**
```
1. Accès restreint
   - Liste de contrôle des accès
   - Authentification OAuth pour Google Sheets
   - Mots de passe forts obligatoires

2. Audit trails
   - Tous les accès loggés
   - Modifications tracées
   - Alertes d'accès anormal

3. Sauvegarde
   - Google Sheets sauvegardé automatiquement
   - Pas de point de défaillance unique
   - Récupération en cas d'incident

4. Formation
   - Membres du bureau formés RGPD
   - Procédures de sécurité documentées
   - Clauses de confidentialité signées
```

### Article 8 : Droits des utilisateurs

**1. Droit d'accès (Article 15 RGPD)**
```
Vous avez le droit de :
✓ Demander si vos données sont traitées
✓ Recevoir une copie de vos données
✓ Connaître la finalité du traitement
✓ Connaître la durée de conservation
✓ Connaître vos droits (17, 18, 19, 20, 21)

Délai de réponse : 30 jours maximum
```

**2. Droit de rectification (Article 16 RGPD)**
```
Vous pouvez :
✓ Rectifier une donnée inexacte
✓ Compléter une donnée incomplète

Note : Pour ce sondage, rectification très limitée
(données minimales : juste collège et IP)
```

**3. Droit à l'oubli (Article 17 RGPD)**
```
Vous pouvez demander la suppression si :
✓ Données plus nécessaires
✓ Retrait du consentement
✓ Opposition au traitement
✓ Conservation dépassée

Exceptions : Obligations légales de conservation
```

**4. Droit à la limitation du traitement (Article 18 RGPD)**
```
Vous pouvez demander à limiter le traitement si :
✓ Contestation de l'exactitude des données
✓ Traitement devenu illégal
✓ Données ne sont plus nécessaires
✓ En attente de suppression
```

**5. Droit de portabilité (Article 20 RGPD)**
```
Vous avez le droit de :
✓ Recevoir vos données dans un format structuré
✓ Les récupérer pour les donner à un tiers
✓ Format : CSV, JSON, etc.

Applicable si traitement sur consentement ou contrat
```

**6. Droit d'opposition (Article 21 RGPD)**
```
Vous pouvez vous opposer au traitement si :
✓ Intérêt légitime (traitement ultérieur)
✓ Intérêt privé plus important que syndicat

Attention : Droit limité ici (processus démocratique)
```

### Article 10 : Détection VPN et anti-fraude

**Technologie utilisée :**
```
API ipapi.co
- Détecte les connexions VPN commerciales
- Détecte les proxies web
- Détecte les datacenters (AWS, Google Cloud)
```

**En cas de détection :**
```
❌ Vote rejeté
❌ IP enregistrée en "tentative frauduleuse"
❌ Message d'erreur affiché

Attention : utiliser VPN = signature de tentative fraude
```

**Anti-doublon :**
```
1er vote : IP enregistrée (localStorage + Google Sheets)
2e vote  : "Cette IP a déjà voté"
           → Vote rejeté
           → Message d'avertissement affiché
```

**Enregistrement des tentatives :**
```
Toute tentative suspecte est enregistrée :
- Date/heure de la tentative
- IP tentative
- Type d'erreur (VPN, doublon)
- Action prise (rejet)

Utilisé pour audits de sécurité et détection fraude.
```
