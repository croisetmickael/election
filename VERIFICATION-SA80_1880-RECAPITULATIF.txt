 🔄 FLUX DE VÉRIFICATION
════════════════════════════════════════════════════════════════════════════════

1. Utilisateur saisit NOM + PRÉNOM
   ↓
2. Application récupère IP (ipapi.co)
   ↓
3. Click "Soumettre"
   ↓
4. fetch() vers Google Apps Script avec : IP + Nom + Prénom
   ↓
5. Google Apps Script cherche dans Sheet "Résultats"
   Structure : [Timestamp | Collège | Prénom | Nom | IP | Pri1 | Pri2 | ...]
   ↓
6. Si trouvé : Retourne { found: true }
   Si NON trouvé : Retourne { found: false }
   ↓
7. Application enregistre réponse dans le Sheet

 🚨 SOLUTIONS AUX ERREURS COURANTES
════════════════════════════════════════════════════════════════════════════════

Erreur : "URL non configurée"
──────────────────────────────
Solution : Vérifier GOOGLE_APPS_SCRIPT_URL dans VERIFICATION-SA80_1880-SHEET.js
           Remplacer "YOUR_GOOGLE_APPS_SCRIPT_URL" par l'URL réelle

Erreur : "Feuille 'Résultats' non trouvée"
──────────────────────────────────────────
Solution : Créer la feuille dans Google Sheet avec createAllSheets()
           Ou créer manuellement une feuille nommée "Résultats"

Erreur : CORS / fetch échoue
──────────────────────────────
Solution : La URL doit être : ...usercontent (pas ...usercode)
           Vérifier que le script est bien déployé

Erreur : Vérification toujours échouée
───────────────────────────────────────
Solution : 
1. Vérifier que les données existent dans le Sheet
2. Vérifier que l'IP est correcte : console.log(app.userIP)
3. Vérifier la correspondance exacte Prénom/Nom (majuscules)
4. Tester manuellement dans la console navigateur
